# KD House of Fashion

Single-page storefront for KD House of Fashion, a Lagos business that imports and exports Nigerian fabrics and finished attire.

[![Portfolio](https://img.shields.io/badge/Adamu_Abubakar-adamu.tech-0f766e?style=flat-square)](https://adamu.tech)

---

## Overview

The page presents the brand's six product lines — fabrics and ankara, abaya and gowns, men's and women's outfits, shoes, school bags, and children's wear — with a weekly edit of featured pieces, the founder's story, and ordering by phone or WhatsApp.

## Features

- Category rails for each product line
- Featured products with sale pricing in naira
- Delivery, pay-on-delivery and returns information
- WhatsApp and phone ordering calls to action

## Run it

No build step. Open `kd-house-of-fashion.html` in a browser, or serve the folder with any static host.

The phone number on the page (`0800 123 4567`) is a placeholder; replace it before going live.
